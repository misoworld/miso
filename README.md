# 평소 · 계절 소요리 주점 운영관리

평소의 소요리·주류·저장음식 운영을 위한 반응형 웹 시제품입니다. 화이트 톤에 톤다운된 빨강·청록·노랑을 적용했습니다.

## 실행

Node.js 18 이상에서 실행합니다. 추가 패키지 설치는 필요하지 않습니다.

```sh
npm start
```

브라우저에서 `http://127.0.0.1:8765/`를 엽니다. 포트를 바꾸려면 `PORT` 환경 변수를 설정합니다.

검사:

```sh
npm test
```

## 화면과 기능

- 대시보드: 음식·주류·논알코올 실적, 시그니처 3종, 계절 메뉴·저장 식재료 활용 방향
- 메뉴: 중복을 통합한 45종과 후보·아이디어 상태, 분류별 조회
- 판매·비용: 기록 추가·수정·삭제, 엑셀 양식 다운로드·검증 후 가져오기
- 판매 단위: 접시·잔·병·도쿠리·인분·개 구분
- 식재료: 입고·폐기·실사 기록과 기초 자료 등록 필요 상태
- 기간 조회, 브라우저 저장, 전체 JSON 백업·복원
- 화면 캔버스(`/#canvas`): 페이지와 팝업 상태 개별 확인
- PC·모바일 반응형 구성

## 자료 및 현재 범위

`dist/pyeongso-data.json`은 사용자가 제공한 메뉴 구상입니다. 실제 판매·비용·재고 기록은 없으며 가격·원가·레시피도 미정입니다. 미등록 값은 실제 실적 0으로 표시하지 않습니다. 메뉴 후보·아이디어는 판매 확정 메뉴가 아닙니다.

이전 카페 데이터는 포함하지 않았습니다. 평소의 기록은 사용 중인 브라우저에 저장되며 다른 기기와 동기화되지 않습니다. 보관과 이동에는 백업 파일을 사용합니다.

수익성·손익·예측·발주·실사 반영 정책은 결정 대기입니다. 재료가 등록되지 않은 상태에서 카페 재료로 임의 연결하지 않습니다.

`docs/01_PRD.md`는 최초 카페 기준 요구사항이며, 이후 사용자 요청으로 매장과 디자인이 평소로 변경되었습니다. 최신 화면은 본 문서와 `docs/02_PYEONGSO.md`를 기준으로 확인하세요. 후자의 원래 작업 폴더 실행 경로는 이 저장소의 `npm start`로 대체됩니다.

브라우저 엑셀 처리는 SheetJS CE 0.18.5(`dist/xlsx.full.min.js`, Apache-2.0)를 사용합니다. 이 저장소 업로드는 웹 호스팅 배포를 포함하지 않습니다.
