# 평소 · 계절 소요리 주점 운영대장

화이트 톤과 톤다운한 청록색(#477f79), 빨간색(#a15d58), 노란색(#b29a51)을 사용한 반응형 운영 시제품입니다.

## 실행

`start-preview.ps1`을 실행하면 `http://127.0.0.1:8765/`에서 확인할 수 있습니다. 화면 캔버스는 `/#canvas`입니다.

## 이번 변경

- 카페 대시보드를 평소의 음식·주류·논알코올 판매 구성으로 전환
- 광어 미소 무침, 네 가지 계절 소요리 플레이트, 닭목살 피망을 시그니처로 강조
- 사용자 제공 목록의 중복을 통합한 45종을 분류·구상 상태와 함께 표시
- 시그니처, 소요리, 식사·마무리, 간단 안주, 저장음식 활용, 주류, 논알코올 필터
- 장아찌·청·절임물을 여러 메뉴에 활용하는 개발 방향 표시
- 판매 입력에 접시·잔·병·도쿠리·인분·개 단위 추가
- 기록 관리, 엑셀 양식·가져오기, 저장·백업·복원, 화면 캔버스 유지
- PC·모바일 및 모든 팝업에 화이트 디자인 적용

## 자료 구분

`dist/pyeongso-data.json`은 사용자 제공 메뉴 구상만 담습니다. 가격·레시피·원가·판매·비용·재고는 임의 생성하지 않았습니다. 메뉴 후보와 아이디어는 확정 판매 메뉴가 아닙니다.

원본 카페 자료 `dist/data.json`과 사용자 첨부 파일은 보존했습니다. 이전 브라우저 저장 `prep-cafe-v1`도 건드리지 않습니다. 평소는 별도 저장 키 `pyeongso-operations-v1`, 별도 백업 형식 `pyeongso-backup-v1`을 사용합니다.

매출이 미등록이면 0원 대신 기록 없음으로 표시합니다. 판매 단위가 다른 수량을 합산하지 않습니다. 수익성·손익·예측·발주와 실사 반영 정책은 PRD의 결정 대기 상태를 유지합니다. 재료 목록이 없으면 카페 재료로 임의 연결하지 않고 기록 준비를 안내합니다.
